# TIR Smartlinks

Official smartlinks for The Imaginary Records releases, served at listen.theimaginaryrecords.in.

- `/` — index of releases
- `/dm` — DM by Dawood Musicxx (Single, 2026)

Each release page is a single self-contained HTML file (logos and QR embedded). No binaries, no build step. Vercel serves this repo as a static site.
